# 零戦 真珠湾攻撃 — Zero: Attack on Pearl Harbor

ブラウザで遊べる3Dフライトシューティング（日本語 / English 対応、タイトル画面で切替）。零式艦上戦闘機二一型の**小隊長機**として列機2機を率い、真珠湾の米太平洋艦隊を攻撃する。

**▶ プレイ（Web 版）: https://techgymjp.github.io/zero/**

## Android アプリ

- パッケージ名: `jp.techgym.zero`（横画面専用）
- 動作確認用 APK（デバッグ署名・テスト広告）: リリース画面 https://github.com/techgymjp/zero/releases/tag/android-latest
- APK を直接: https://github.com/techgymjp/zero/releases/latest/download/zero.apk

<img src="docs/apk-qr.png" width="200" alt="Android 版のリリース画面の QR コード">

Android 端末でリリース画面を開き、`zero.apk` をタップしてインストールします（「提供元不明のアプリ」の許可が必要）。

### 構成
- [Capacitor](https://capacitorjs.com/) 8 でゲームのファイルをアプリに同梱（オフラインで遊べる）。`npm run build:app` で `www/` にまとめる
- 広告（Google AdMob, `js/ads.js`）: バナーはタイトル・あそびかた・ポーズ・結果画面だけ。全画面広告はプレイ開始・タイトルに戻る・ポーズからの再開・もう一度のたび。リワード広告は撃墜されたときの「広告を見てその場で復活」（1 ゲーム 3 回まで、残機を減らさない）
- 戻るボタン（プレイ中はポーズ、タイトル・結果画面では終了）、バックグラウンドで自動ポーズ、結果のシェア
- GitHub Actions（`.github/workflows/android.yml`）が APK を作り、Release `android-latest` に載せる。Secrets を登録すると Google Play 用の署名付き AAB も作る

## 想定（史実との違い）
- 史実では奇襲となったが、本作では **米軍が臨戦態勢** にある。オパナ・レーダーが編隊を探知し、対空砲火は即応、各飛行場（ホイラー・ヒッカム・ハレイワ・エワ・ベローズ・カネオヘ・フォード島）から迎撃機が緊急発進する。
- 米空母 **レキシントン・サラトガ・エンタープライズ** が真珠湾南方を哨戒中で、撃沈するまで艦載機を発艦させ続ける。
- 米軍機は総数 **400機**（地上駐機機・哨戒機・空母搭載機の合計）。

## 勝利条件
**戦艦8隻（ネバダ、アリゾナ、テネシー、ウェストバージニア、メリーランド、オクラホマ、カリフォルニア、ペンシルベニア）と空母3隻をすべて撃沈。**

## 作戦の流れ
1. 07:40（現地時間）、**空母赤城の甲板から発艦**して開始。発艦後に列機2機が合流する。第一次攻撃隊はオアフ島北端 **カフク岬上空** から進撃する。
2. 攻撃隊は **西海岸沿いに南下**（ワイアナエ山脈の西側）し、**バーバーズ岬** で北東に転じて真珠湾へ突入する（地図に点線で表示）。
3. 制空隊の零戦はホイラー・ヒッカム・カネオヘへ散開し地上の米軍機を銃撃する。
4. 以後、第二次以降の攻撃隊（九七艦攻・九九艦爆）がバーバーズ岬方面から増援として到着する。
5. 爆弾を使い切ったら真珠湾沖（南西）の **空母赤城** に着艦して補給（L キーで自動着艦）。

## 操作
| キー | 動作 |
|---|---|
| W / S（↑ / ↓） | 上昇（機首上げ） / 下降（機首下げ） |
| A / D（← / →） | 横転 |
| Q / E | 方向舵 |
| Shift・R / Ctrl・F | スロットル 増 / 減 |
| Space・クリック | 機銃（20mm） |
| B | 爆弾投下（250kg → 60kg） |
| G | 脚の上げ下げ |
| V | 視点切替（追尾 / 操縦席 / 遠景） |
| 中ボタン or Shift+左ドラッグ | 視点回転 |
| T | 時間加速（×4 / ×8） |
| M | 地図の縮尺 |
| N | 列機への命令（編隊・援護 / 自由戦闘） |
| L | 自動着艦（赤城の近く） |
| P / Esc | 一時停止 |
| H | ヘルプ |

ゲームパッド: 左スティック=操縦、右スティック=方向舵、RT/LT=機銃、A=爆弾、Y=視点、LB/RB=スロットル。

## 再現した要素
- **地形**: オアフ島の海岸線（緯度経度から変換）、ワイアナエ山脈（カアラ山 1,227m）・コオラウ山脈（東側が急峻なパリ）、ダイヤモンドヘッド等の火口丘、真珠湾の東・中・西入江とフォード島、乾ドック、石油タンク群。
- **艦艇**: 戦艦列（F岸壁）の史実配置 — カリフォルニア／ネオショー／メリーランド＋オクラホマ／テネシー＋ウェストバージニア／アリゾナ＋ヴェスタル／ネバダ、第1乾ドックのペンシルベニア。艦型ごとの主砲配置（三連装・連装・16インチ連装）、籠マスト／三脚マスト、煙突数。空母赤城（左舷艦橋・下向き煙突）、加賀、戦艦霧島（パゴダマスト）、レキシントン級（巨大煙突・8インチ連装砲塔）、ヨークタウン級。
- **航空機**: 零戦二一型（AI-101 小隊長機の胴体帯）、九七式艦攻（魚雷）、九九式艦爆（固定脚）、P-40B、F4F-3、駐機中の B-17・PBY。1941年当時の米軍標識（中央に赤丸）。
- **飛行モデル**: 迎角・揚力・抗力・推力（栄一二型）に基づく簡易物理。失速、高速時の舵の重さ、尾輪式の地上滑走、空母からの発艦・着艦（制動索）。

## 技術
- [three.js](https://threejs.org/) r160（`vendor/` に同梱、外部CDN不要）
- モデル・テクスチャ・効果音はすべてコードで生成（外部アセットなし）
- ビルド不要。静的ファイルを配信するだけで動作します:
  ```bash
  python3 -m http.server 8000
  ```
